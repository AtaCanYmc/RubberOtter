# Security Policy

## Supported Versions

Only the latest stable release of the Rubber Otter firmware receives security updates.

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

The Rubber Otter team takes security vulnerabilities seriously.

If you discover a security vulnerability in this project (e.g. unexpected HID payload execution risks, memory corruption in ring buffers, or unauthorized command execution), please report it responsibly:

1. **Do NOT open a public GitHub issue.**
2. Send a security report to the repository maintainers via private disclosure or email.
3. Include detailed steps to reproduce the vulnerability, along with sample payload byte sequences.

### Response Timeline

- **Acknowledgement**: Within 48 hours of report submission.
- **Assessment & Patch**: Security fixes will be prioritized and merged within 14 days.
- **Public Disclosure**: Once a patched release is published via Release Please.
