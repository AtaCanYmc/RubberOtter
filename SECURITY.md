# Security Policy

## Supported Versions

We actively issue security updates for the latest major version of **RubberOtterWeb**.

| Version | Supported          |
| ------- | ------------------ |
| 2.x     | :white_check_mark: |
| 1.x     | :x:                |

---

## Reporting a Vulnerability

We take the security of **RubberOtterWeb** seriously. If you discover a security vulnerability or security-related flaw in Web Bluetooth transmission, PWA asset integrity, or hardware command encoding:

1. **Do NOT open a public GitHub issue.**
2. Send a private report detailing the vulnerability to the project maintainers via email or private security disclosure.
3. Include clear steps to reproduce the vulnerability, along with any relevant proof-of-concept payload or browser environment details.

### What to Expect

- **Acknowledgment**: You will receive an initial response acknowledging your submission within 48 hours.
- **Triage & Fix**: The maintainers will investigate the vulnerability and prepare a patch.
- **Disclosure**: Once the fix is released, a public disclosure notice will be posted alongside the patch release.

Thank you for helping keep **RubberOtterWeb** secure!
