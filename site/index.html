        02 // HARDWARE & WIRING
        
Dual-chip HID with 3.3V BLE isolation.

      


      

        

          

            PINOUT & LOGIC LEVEL
            
ATmega32U4 to HM-10 UART Bridge

            

              Connect HM-10 TX directly to Pro Micro Pin 0 (RX1). Route 5V Pin 1 (TX1) through a 1kΩ / 2kΩ resistor voltage divider before HM-10 RX to protect the 3.3V BLE receiver IC.
            

          


          

            WIRE PROTOCOL
            
384BYTES

            
Max framed payload per RubberOtter v1 STX/ETX XOR packet with 6-byte ACK replies.

          


          

            HAPTIC FEEDBACK
            
Pin 2 Vibration Driver

            
Active-HIGH GPIO pulse on Pin 2 drives a coin vibration motor via 2N2222 NPN or MOSFET for tactile confirmation.

          


          

            SEPARATION OF CONCERNS
            
Dedicated Flasher, Unified Control PWA

            

              This page handles ATmega32U4 firmware flashing only. Use RubberDeck for live BLE 5.0 and USB CDC control, or install pip install rubberotter for Python SDK, CLI, and MCP automation.
